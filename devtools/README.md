# Devtools

The one-click version synchronization script has been retired.

Use the changelog and manual metadata updates instead:

- Update `pyproject.toml`, plugin manifests, and plugin class versions together when
  the project version changes.
- Record the change in `CHANGELOG.md`.
- Keep the README and AGENTS docs in sync with the current naming and versioning
  model.

For standalone maintenance scripts, see [scripts/README.md](../scripts/README.md).
